# ParishKit reference material

This directory preserves non-normative source material used while developing
the project specifications. Implementations must follow the specifications in
[`docs/specs/`](../specs/README.md), not these historical captures.

- [Stewardship initial prompt](stewardship-initial-prompt.md) preserves the
  original campaign narrative for traceability.
- [Local-review references](local-review/) preserve the review workflows used
  during specification development. The installed skills outside this
  repository are authoritative; these files are not portable instructions.
