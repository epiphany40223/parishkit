{% load i18n static stewardship %}{% comment %} Admin sidebar, built from accounts/admin_navigation.py (admin-portal spec, "Menu groups" and "Stable menu shape"). The outer disclosure is the narrow screens' Menu toggle; ui-v1.js closes it there and keeps it open on wide screens. aria-current marks the current page. Each menu group is a native disclosure whose summary is the group's title and names its list of entries. The title is not a heading inside the summary, because some screen readers then drop the summary's disclosure role. Groups render open; admin-menu-state-v1.js closes the ones this browser remembers as collapsed, except the group holding the current page (data-menu-current), which always stays open. admin-menu-state-v1.js loads without defer right after the sidebar, so it sets the remembered groups and restores the menu's scroll position (#620) once the menu is parsed and before the page content is, avoiding a visible jump. It must not move to the head (the menu does not exist yet there) or be deferred (the page would show first and then jump). An entry the viewer's role may open but that is unavailable right now is greyed out, never removed: a link without href (so activating it does nothing) that stays in the tab order, with its reason as its accessible description. admin-menu-v1.js shows the reason's tip on hover, keyboard focus and tap, and Escape or a tap elsewhere hides it. Sign out is a POST form (logout is CSRF-protected) styled as the last menu entry. {% endcomment %}
