{% extends 'stewardship/admin-base.html' %}{% load i18n stewardship %} {% block title %}{% translate "Report emails" %}{% endblock %} {% block content %}{% comment %} Mail › Report emails (report-emails spec, "Report emails page", #1786; report_email_views). One region (#report-emails-table) holds the status line, the action forms, the table, each report's past sends (each with its own row navigator, whose page and size are in the address) and the deleted reports, so the hidden re-read link (every 30 seconds) and every row action redraw it in place. Row actions are icon buttons that open the row actions' confirmation dialog; an action the row cannot take now stays in place, unavailable, with its reason in its tooltip. Preview (#2035) posts the report to the report-preview form, whose answer fills the "Preview — not sent" review dialog, which has no Apply. Send a test to me (#2036) posts the report through the report-test form from the page script, in place, and writes its result ("Test of Weekly report sent to you at 9:42 AM.") to the status line above the table, which the 30-second re-read leaves alone. Staff see no recipients, no actions and no Edit links. A Paused status takes the Warning look of the UX conventions' status indicators (#1966): the warning icon, hidden from assistive technology, and the warning colours, with the word kept, since a paused report silently stops sending. {% endcomment %}
