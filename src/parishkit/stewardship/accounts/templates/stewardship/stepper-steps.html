Each bar segment of a step that can be opened is a link to its page, named "Step N of M: label — status" and marked aria-current="step" when it is the current step; the same text shows as a floating tooltip on hover and keyboard focus, which moves nothing. A step that cannot open yet (a missing prerequisite, the ordering rule or the running data load) is not a link: its segment stays focusable but aria-disabled, and its name and tooltip say why ("Not available yet: ..."). Clicking or tapping it only focuses it, which shows that tooltip (ui-v1.js), as the Family bar does. Following a segment saves nothing. The list below repeats the same steps inside a collapsed disclosure, and on a screen 64rem wide or wider (#1404) in a second copy that is always open; stepper-v1.css shows exactly one of the two, so the switch is CSS only and nothing moves after the page loads.
