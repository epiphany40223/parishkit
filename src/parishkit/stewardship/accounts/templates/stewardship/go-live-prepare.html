One frame, as Check's: the heading, the About panel, the Go live step bar, the step's content and one action row (the secondary Stop go-live first, then exactly one primary, or none while there is nothing to do), with the reserved status line under it. No Back: Check cannot be redone without stopping. The content is three stage boxes (components/stage-boxes.html): Delete Testing data, Refresh ParishSoft data and Prepare Family links, then one detail line for the current box and one line saying what to do. Every state draws the same boxes and both lines, so a change of state moves nothing (no layout shift). The step bar, content and row are one region (#go-live-prepare) that updates itself (live-status-v1.js): closely while the work moves by itself, every 30 seconds while it waits for the Administrator, so a change made in another tab shows here; there is no Refresh link (#1586). Its data-live-announce sentence is read out only when it changes. Once go-live is no longer in progress here (stopped, or confirmed elsewhere) the region settles and its primary, marked data-live-follow, opens the page that now applies. A reload draws the same state from the server. ``stage`` is go_live_prepare's Prepare: running, failed, again, ready, closed, stopped, not_started or confirmed. {% endcomment %} {% block title %}{% translate "Go live" %}{% endblock %} {% block head %}{% if not admin_chrome.campaign_wizard %}{% endif %}{% endblock %} {% block content %}
