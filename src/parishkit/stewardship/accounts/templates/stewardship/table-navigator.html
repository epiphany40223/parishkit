It shows the rows shown and "Page N of M"; a windowed table whose bounded count stopped short says "more than" and leaves out the page count. Each control is a real request target that ui-v1.js sends: a GET table uses links and a GET form, a POST table (private report filters) uses small CSRF-protected POST forms carrying the filters as hidden fields, so they never reach a URL.
