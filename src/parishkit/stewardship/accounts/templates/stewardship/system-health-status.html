{% load i18n stewardship %}{% comment %} The System health status region (ADM-13, #530; the dashboard, #1214), shared by the page and the passive status fragment that live-status-v1.js polls every 10 seconds. ``health`` is system_health.SystemHealth and ``dashboard`` its system_health.Dashboard. The page and the fragment's slow recheck (``?slow=1``, #1790) pass status_url, which carries the page-load tiles' states (``?loaded=``); an ordinary poll passes none, so the region keeps the address it has. data-live-slow-every asks live-status-v1.js for that recheck about every 5 minutes. The region shows only the overall status line, the page's first h2: All working, the number of Warning tiles, or the number of Error tiles (and Warning tiles), counting tiles, not problems (decision 2 of 2026-10-13). Its Not current form ("Not checked since 3:42 PM") is drawn from the start and shown instead, inside the line's fixed height, while the dashboard is [data-not-current]: live-status-v1.js says when (data-live-not-current), and system-health-v1.js fills in the time. The rest of the region is copies for the tiles, which sit outside it so a poll never closes one: each polled tile's summary row, problems and panel content, and the action buttons, as template[data-live-mirror] elements that live-status-v1.js puts into their data-live-mirror-targets, including Accept this change once's section, which is empty unless the refusal shown can be accepted or was accepted. The two page-load tiles' summary rows and panel content are copied only by the page and a slow recheck, which read them (not ``loaded_echoed``); their copies are data-live-mirror-lasting: the script takes them out of the region (so they never count as a change to it) and keeps applying the last one through the ordinary polls that carry none. The data-live-key element names the refusal shown, so an open Accept this change once preview of another one is marked changed. It is not itself a live region: screen readers hear data-live-announce, copied into the page's announcer only when the line's text or the set of tiles it counts changes. Nothing here changes from one poll to the next unless the state does, so an unchanged poll leaves the region alone: "Last checked" sits outside it, and how long ago the last backup finished is counted in the browser (time[data-live-since]). {% endcomment %}
