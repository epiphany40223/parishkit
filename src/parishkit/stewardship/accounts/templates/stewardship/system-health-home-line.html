{% load i18n stewardship %}{% comment %} One System health problem as a line on Home (admin-portal spec, "Health problems on Home and in the banner", #1214). ``problem`` is a system_health.Problem. The line shows the registry's icon and state word (a status indicator, ui-conventions "Status indicators"), the page's own sentence (system-health-problem.html), and one link to the problem's tile. When the sentence already links that tile ("See Mail sender", "See the counts", "See Version"; Problem.links_tile), the line adds no second link. While the configured backup key cannot be read, System health cannot be shown, so that line links no tile (Problem.tile_link). An error has the error notice's look, a warning the warning one's, as the tiles' problem items do. {% endcomment %}
