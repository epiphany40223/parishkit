{% load i18n stewardship %}{% comment %} The ParishSoft refresh schedule editor (#632; admin-portal spec, "ParishSoft refresh schedule settings"). Rule rows, skip rows and the switch are posted with the page's other settings; presets and "Edit as text" only fill rows. The server checks everything: refresh-schedule-v1.js posts the unsaved rows to the read-only check (data-check-url) as typing pauses and puts its answer in the data-schedule-part elements and each row's messages. The line beside Save (integration-settings.html) is the check's only live region, and it also says the problems of the schedule as a whole, so nothing the check draws appears above the rows. The data-*-text attributes are the script's words, translated here. {% endcomment %}{% with editor=schedule.editor %}
