It loads in the head without defer, so it runs before the body is parsed and a browser with JavaScript never shows the panel. The panel has no heading element: it stays in the DOM (hidden) on every page, and a second h1 would confuse headings navigation and tests. A CSS rule rather than a noscript element covers that failed-load case too. The content security policy still allows no inline script or style.
