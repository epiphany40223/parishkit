{% load i18n %}{% comment %} The Appearance switch at the top right of every Admin page's header, sign-in and setup included (#1264; ui-conventions "Colour scheme"). It chooses the Admin portal's light or dark scheme for this browser: sun = Light, moon = Dark, monitor = Match this device. It is a group of native radio buttons, so it is one Tab stop, the arrow keys move the choice, and a screen reader hears "Appearance", each choice's name and which is selected. Each icon's label carries a matching title tooltip, as the table action icons do. The icons are drawn inline (presentation attributes in currentColor), so they need no request and stay inside the content security policy. It has no form and nothing is checked in the markup: the server does not know the choice. admin-gate-v1.js, which runs in the head, keeps the choice on the root element as data-theme-choice, so ui-v1.css shows the selected icon from the first paint; the same script checks the matching radio and applies a change at once, in place. autocomplete="off" stops the browser restoring an older check over the saved choice on reload. {% endcomment %}
