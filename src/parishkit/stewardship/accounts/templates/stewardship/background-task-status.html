{% load i18n stewardship %}{% comment %} The task's live status region, shared by the task page and the passive status fragment that live-status-v1.js polls. The poll is never audited as a page view, and reading it never renews idle time. Only the page passes status_url, which points the poller at the fragment instead of the page. Once the task has ended, a hidden follow-up link (data-live-follow with data-in-place) has live-status-v1.js bring the rest of the page, such as the Task history table and any Retry panel, up to date in place (#869). Refresh from ParishSoft draws it too, for the run it requested (#521), and names its own region as region_id, which also words a failure for that page, where no history or Retry panel follows; its poll asks for the same (?view=refresh), so a failure seen by a poll is worded the same way. Update ParishSoft draws it for the check it requested (#528), with publication_check set (?view=publication), and read_unconfirmed when the check stopped because ParishSoft's contact read is not confirmed yet; and for its newest plan's update run (#1688), with update_run set (?view=update), which counts the Members done and words a run that stopped for that page, where Run again follows. A ParishSoft refresh (``stages``, campaign_wizard.task_stages) draws its four phases as the shared stage boxes (components/stage-boxes.html, #1579), right under the heading so the lines below changing with the state never move them, instead of a "Step:" line. Its region is then not aria-live, since its count changes on every poll: its data-live-announce sentence (state and current stage) is read out by the page's announcer, outside the region, only when it changes. Other tasks keep aria-live. While Start the load is In progress (the run waits for a worker, #1916, #1947), the progress line says the shared queued sentence (stages.QUEUED), as every page with a queued job in stage boxes does. It is checked before the record count: a run waiting to retry keeps its last attempt's count until a worker claims it again, as Load ParishSoft data orders it. {% endcomment %}
