It is its own menu page, so its heading stays Production activation. While a direct activation's initial mail preparation is unfinished it draws the Go live step bar (Step 4 of 4); afterwards, and for a scheduled campaign, it is the ordinary menu page with no step bar (wizard rule 12). A direct activation shows three stage boxes (components/stage-boxes.html): Go live (Done), Prepare initial emails and Sending, which is In progress with a Sent mail link once preparation is done, never Done, so the page never claims delivery. One detail line and one note line follow, drawn in every state with reserved rows, and the action row keeps one button's height even when empty, so a change of state moves nothing (no layout shift, .production-line and .production-actions in stepper-v1.css); the preview compared with the preparation outcomes is in a disclosure. A scheduled campaign says when it starts and offers Cancel go-live, which opens the review dialog, while the start has not passed and live delivery is not paused. The content and action row are one region (#production-status) that updates itself (live-status-v1.js); the step bar sits above it, drawn only when the page is opened, so a finished preparation never moves the page while it is watched. The region updates closely while preparation runs, every 30 seconds while a Retry waits or the campaign is scheduled, and not at all once nothing can change by itself. There is no Refresh link (#1586); a reload draws the same state. ``state`` is confirmation_views._state's: preparing, retrying, failed, prepared, scheduled, started or closed. {% endcomment %} {% block title %}{% translate "Production activation" %}{% endblock %} {% block head %}{% if not admin_chrome.campaign_wizard %}{% endif %}{% endblock %} {% block content %}
