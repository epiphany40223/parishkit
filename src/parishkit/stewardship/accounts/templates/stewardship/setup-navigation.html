{% load i18n stewardship %}{% comment %} The wizard's action row, the ui-conventions "Stepper button row" (#1936): each control names its slot (data-nav-slot), Back at the left and the one primary at the right, laid out by stepper-v1.css. A form with the complete gate (data-require-complete, #563) passes complete_hint, the id of its hint: the submit button names it, and it sits below the row so its line never moves the buttons. A page that renders the submit button unavailable passes disabled_reason, the id of the visible text saying why: the button is then disabled and names that text. A status page whose Continue waits on background work (Loading parish data, #1968) passes continue_label with either continue_url (Continue is a link there, to the step continue_name names, else the next one) or continue_reason (the id of the visible reason: Continue is drawn as a disabled button naming it), so the row keeps its place either way. A form whose buttons say which answer they give (ParishSoft connection's organization choice, #1554) passes submit_value, sent as the primary's action, and secondary_label with secondary_value for the centered secondary submit (No or Cancel), which skips the complete gate. A step that is skipped while a box is unticked (Off-site backups, #2200) passes skip_label, the label the primary has then, with switch_name (the box) and switch_on (whether it is ticked now): both labels are drawn in one grid cell, the box choosing which shows (data-show-when), so the button keeps the wider one's width. complete_hint_reserve keeps the hint's line while it is empty (data-complete-hint="reserve"). {% endcomment %}
