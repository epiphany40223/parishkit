{% translate "One-time setup in Google (for your Google Workspace administrator)" %}
  1. {% translate "In the Google Cloud project that owns the service account used for mail, enable the Google Drive API (APIs & Services → Library → Google Drive API → Enable)." %}
  2. {% translate "In the Google Admin console, open Security → Access and data control → API controls → Manage domain-wide delegation. Edit the service account's client ID and add this scope next to the existing mail scope:" %} https://www.googleapis.com/auth/drive
  3. {% translate "Create a folder for the backups, preferably in a shared drive so it does not belong to one person's account. Add the delegated mailbox user shown on the Google Workspace mail page as a member of that shared drive with Content manager access." %}
  4. {% translate "Open the folder, copy its link from the address bar, paste it below, then select Test access. When the test succeeds, select Save." %}

{% translate "Changes to domain-wide delegation can take several minutes to take effect." %}
