{% load i18n %}{% comment %} A setup test page's live status region (Test email, Test Slack; #1354): the recent tests and their states. The page and the passive status fragment the page polls (?format=status, never renewing idle time) both draw it, so live-status-v1.js swaps in the fresh list while a test is queued or being sent (data-live-pending). Only the page passes status_url. The region is not itself aria-live: data-live-announce names the newest test's state, read out by the page's announcer only when it changes. Once no test is in flight, the hidden follow-up link (data-live-follow, data-in-place-quiet) re-reads the page's panel in place, so the acknowledgement box, Send another test and Continue come from the server for the settled result, without a reload and without moving focus. ``empty`` is the page's own words for a list with no tests yet. The region's checking-problem line (live-status-v1.js) has the id setup-test-problem, which a Send held while a test is pending names beside setup-test-pending (setup-test-actions.html) while it shows (#1332). {% endcomment %}
