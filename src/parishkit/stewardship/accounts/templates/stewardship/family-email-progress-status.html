{% load i18n stewardship %}{% comment %} The Family email progress region, shared by the page and the passive status fragment that live-status-v1.js polls. It shows live progress only while a send is in progress (send.active); otherwise it says no send is in progress, summarises the most recent send in one line and links to Outgoing mail, the permanent record. It keeps polling while there is a current campaign, so a new send appears by itself. It is not itself a live region: its counts change on every poll, so screen readers instead hear data-live-announce, copied into the page's announcer only when that coarse status changes. Only the page passes status_url. {% endcomment %}
