When the file becomes ready while the page watches, the download starts once by itself. The page has no Refresh link (#1586). Retry export and Cancel export post in place too (form[data-in-place], #519): each view redirects back to this page, whose panel is swapped in. The button is usually gone then, so focus falls back to the panel's first heading, else the panel itself. A refusal is the fixed error page, which draws no panel, so it is shown whole. A ready file's Download form names its window's end (data-download-until): when it passes while the page is open, live-status-v1.js disables Download in place and the "until" line just below it, whose two sentences share one grid cell so its height never changes, shows the expired one instead (#1398; UX conventions, "Point-in-time downloads"). The server still answers a later Download with the 410 page. While the export's task is still queued (not yet claimed by a worker), ``wait`` says why it has not started and how long it has waited (#340). {% endcomment %}
