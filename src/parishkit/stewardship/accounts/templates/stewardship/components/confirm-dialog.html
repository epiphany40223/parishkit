{% load i18n stewardship %}{% comment %} The shared confirmation dialog of action tables (admin-portal spec, "Row actions and confirmation", #879): a native modal that ui-v1.js opens from a control marked data-confirm-open="" (a row's Delete, or the bulk bar's button for the ticked rows). It never uses confirm(). - title_one / title_many and done_one / done_many are the title and the announcement after success, with {name} (the row's data-confirm-name) or {count} filled in by the script. - body and caution say what the action does and what it cannot undo. - form_id names the table's form: confirming posts its fields (CSRF and any base version) plus the chosen rows, without a page load. - The status line ("Working…") is reserved under the buttons, and a refusal is shown below that, so neither ever moves a button. The dialog is anchored to the top of the window (ui-v1.css), so a growing dialog grows downwards. - fallback names the element that takes focus when the control that opened the dialog is gone (its row was removed). {% endcomment %}
