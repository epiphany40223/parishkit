Its parts, in order: - the notice line, reserved while empty so a notice never moves the table; - the filters, always open (UX conventions, "Admin tables": a worklist has no Filters disclosure), Stage first with its counts, then the stream's own (worklist.filters_template); - the table region: the selection bar (the bulk buttons, which wait until every ticked row offers their action, data-confirm-kind; Add, for readers allowed to add there), the table in the shared column order and each row's action icons, and each Edit's value editor; - the stream's export pane below the table (worklist.export_template). An action the reader's role does not allow is not drawn at all. Every decision posts to the page itself with the page's view, and the page is redrawn from the answer (answer_page), so nothing reloads; focus returns to the same action's icon in the redrawn row (data-row-action). {% endcomment %}{% with w=worklist %}
