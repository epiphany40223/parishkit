Each row carries the progress line and a slim bar (a native progress element; the line already says it, so the bar is hidden from screen readers), then Previous, Finish and Next in the stepper's three fixed slots (ui-conventions "Stepper button row"), as the Family form's row: Previous always on the left, Finish always in the middle (on the last page too, R52 Part W) and Next always on the right; page 1 keeps Previous's slot empty and the last page Next's, so no button moves from page to page. Each is a small POST form (CSRF; the address names the run and the target page): Previous and Next post to the page they open, Finish to this page with finish=1. They never ask, save or discard anything. The page a move opens puts focus on the control used (``focus_previous`` or ``focus_next``, from the view's ``focus``; on the last page, which has no Next, Finish takes Next's focus), so Enter moves on again. The control is marked data-review-focus and ui-v1.js focuses it without scrolling: an autofocus would scroll a phone's page down to the bottom row's sticky spot (Chromium), moving both rows off their screen spots. {% endcomment %}
