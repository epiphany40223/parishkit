Each row carries the progress line and a slim bar (a native progress element; the line already says it, so the bar is hidden from screen readers), then Previous, Finish and Next in the stepper's three fixed slots (ui-conventions "Stepper button row"): page 1 keeps Previous's slot empty, and on the last page Next's slot reads Finish and the middle slot is empty, so no button moves from page to page. Each is a small POST form (CSRF; the address names the run and the target page): Previous and Next post to the page they open, Finish to this page with finish=1. They never ask, save or discard anything.
