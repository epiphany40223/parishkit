{% load i18n %}{% comment %} The census worklist's address editor (#1785), shared by Edit (census-worklist-value.html) and Add (census-worklist-add.html): an address's parts, named value_, in the Family form's order, Country first (census.address_editor draws ``address``). For the United States, State is a drop-down of the regions the server accepts and the postal field reads "ZIP code"; for any other country, State is free text and the postal field reads "Postal code". data-show-when swaps the two State controls in place: both are named value_region, and only the shown one is enabled and sent; each keeps its value while the other shows. A US region the list does not offer is drawn as its own selected choice, so the server refuses it at State instead of the editor dropping it. The server checks every part with the Family form's address rules. {% endcomment %}
