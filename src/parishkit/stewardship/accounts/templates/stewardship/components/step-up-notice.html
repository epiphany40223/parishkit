Pages never word their own: a guard test fails on step-up phrasing ("For security", "sign-in from the last", ...) anywhere else. A page shows it only when a step-up would be asked for now (`fresh` is false, #1159), or for an attempt refused for a stale sign-in. Include with: action= next=: draws the shared Confirm control (reauthenticate.html). Omit it only when the notice sits inside the action's own form, where a nested form cannot go: the action then asks for the step-up when it is sent. next_label= when `next` is another page. later=True, without `next`: the action is on a later step, not this page's own controls, so the notice says that step asks (the setup start page, whose Start setup needs no fresh sign-in). outcome= note= id= marker, marker_value: an extra data- attribute for the page's own hooks (data-step-up-notice is always there). role="alert" or "status": a live-region role for the sentence alone (never the whole notice, so the Confirm control is not read as part of the announcement), on a page that shows the notice as an answer. LOCAL has no Google (#619): its branch never mentions Google, and reauthenticate.html gives LOCAL's own instructions. {% endcomment %}
