{% load i18n %}{% comment %} Stage boxes (UX conventions, "Stage boxes"): one box per major stage of a long piece of work, in order, left to right, wrapping on a narrow screen (.stage-boxes in ui-v1.css). ``stages`` is a list of {key, label, state, status} (accounts/stages.py words ``status``); ``state`` is done, active, waiting or failed, or operator (Finishing setup). Each box names its stage and its state in words, so its text, and its accessible name as a list item, carry the state; the mark and colour only reinforce it. An In progress box draws the shared working spinner (components/spinner.html) in its mark's place, hidden from assistive technology. ``label`` names the list, ``key_attribute`` is the data attribute (without "data-") that carries each stage's key, and ``detail``, when given, is a template drawn inside each box after its status, with the stage as ``step`` (Finishing setup's per-step explanation). Loading parish data, Finishing setup, Load ParishSoft data (#1404 PR 5) and the Go live page's Prepare step (#1585) draw it. {% endcomment %}
