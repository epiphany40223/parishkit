{% load i18n stewardship %}{% comment %} A grid of link cards (ui-conventions "Overview pages", #1673): each card is one place to go next. ``cards`` are rows with ``label``, ``url`` (None while the menu greys the page out), ``reason`` (the menu's reason then), ``count`` (None for none), ``stage`` (the stages the count adds up, before it) and ``note`` (what the count means, after it), such as home_steps.Step; ``cards_labelledby`` is the id of the heading that names the list. A card that links reads its label, then its stages, count and note, in DOM order, so the link's name is "Census changes To review and Conflict: 4" (#2331). The start bar only reinforces the count: warning while above zero, accent at zero, the plain edge without a count. A greyed card is muted text with the reason, never a link. A row's ``other`` (home_steps.Other, or None) is a second, small link after the card's own, at its end: its count and short note ("1 in Testing"), with ``more`` finishing its name for screen readers. The card keeps its two lines, and the start bar warns while either count is above zero (#1576). With ``live`` (a scope, such as its panel's stream) each card is an item of a review region (#2174), keyed by its label within that scope, so its count updates itself. {% endcomment %}
