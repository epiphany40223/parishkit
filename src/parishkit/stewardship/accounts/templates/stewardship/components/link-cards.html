{% load i18n stewardship %}{% comment %} A grid of link cards (ui-conventions "Overview pages", #1673): each card is one place to go next. ``cards`` are rows with ``label``, ``url`` (None while the menu greys the page out), ``reason`` (the menu's reason then), ``count`` (None for none) and ``note`` (what the count means), such as home_steps.Step; ``cards_labelledby`` is the id of the heading that names the list. A card that links reads its label, then its count and note, in DOM order, so the link's name is "Census changes 4 to do". The start bar only reinforces the count: warning while above zero, accent at zero, the plain edge without a count. A greyed card is muted text with the reason, never a link. {% endcomment %}
