Each action is an icon button through the shared {% button %} tag, named for its row ("Edit Reminder 2") with the same words as its tooltip: - Edit (when `edit` is given) links to the row's own edit page. - Delete (when `delete` is given) is a type="button" control that never submits by itself: ui-v1.js opens the confirmation dialog `confirm` names (components/confirm-dialog.html), which posts `delete` as the value of `field` with the table's form once confirmed. The dialog names the row by `confirm_name` (the tag's default is `name`), and `caution` marks it data-confirm-caution for a caution said only for marked rows. With verb="revoke" the same control says Revoke and draws the revoke icon (Automation access); with verb="remove" it says Remove and draws the remove icon (Past campaigns); with verb="sign_out" it says Sign out with the revoke icon (Signed-in sessions).
