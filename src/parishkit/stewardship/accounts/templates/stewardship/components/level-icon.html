{% comment %} One severity or state icon from a matched set, or the audit-record clipboard, drawn inline so it needs no extra request and stays inside the page's CSP (presentation attributes only, no style attribute). It is hidden from assistive technology: the visible word beside it carries the meaning (in the System logs Level column the word is screen-reader text plus a tooltip). `level` is the lowercase level name, a status indicator's state icon ("ok" or "unknown", ui-conventions "Status indicators", #1214), or "audit" for an audit record (#601): a clipboard, so it differs in shape, not only color, from the level icons. Every mark is cut out of its shape (fill-rule evenodd) or drawn as an outline, always in currentColor, never a fixed color, so forced-colors mode keeps every shape and mark. Colors come from the .level-icon-* classes, which read the design tokens. {% endcomment %}
