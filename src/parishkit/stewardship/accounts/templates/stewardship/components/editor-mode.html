- mode_id: the toggle's id, and the prefix of its radios' and dialog's ids. - mode: "basic" or "advanced", the mode the editor opens in (the view works it out from the stored setting, as the convention says). - name (optional, default editor_mode): the field that sends the mode with the save. The toggle is marked data-not-a-change, so switching modes alone does not make Review available; so is the Basic panel, whose choices only write the Advanced fields (the configuration). - legend (optional, default "Mode"): the group's visible label. - no_basic_title / no_basic_body: the dialog's title ("Your custom schedule has no basic equivalent.") and what switching does. The dialog is included with "only", so a page's own context (an editor's review, csrf and the like) never turns it into another dialog. {% endcomment %}
