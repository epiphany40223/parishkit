{% load i18n %}{% comment %} The note of a review worklist dialog (#1681), included by components/confirm-dialog.html (fields_template) inside the dialog's form, or by a stream's value editor after its own fields. `note_name` is the field's name: "note" for one item's decision, "bulk_note" for the bulk bar's. Every decision takes the optional note; reopening an Ignored item, or undoing a terminal step, requires it (review pipeline spec, "Reviewed stage", "Undoing a terminal stage", #1840): ui-v1.js sets the nameless choice field from the opening control's data-confirm-choice, and the note is required while it says "reopen" (data-required-when). Its label follows in place: "Note (optional)", or "Note (required)" only while the chosen action needs it (ui-v1.js, data-required-label). Confirm then waits, saying why in the reserved line below, which the dialog's accept_hint names. The note goes back to empty whenever the dialog opens (data-confirm-reset), so an earlier note is never recorded again unasked. An action that records no note (the "no_note" choice, web/review_worklist.build's `silent`) hides the label and field (data-note-field) while its dialog is open; the empty note is still posted. {% endcomment %}
