{% translate "Why sends are waiting" %}
{% translate "Every reason Family email is waiting right now: a pause an Administrator chose, this server's daily limit, Gmail's own sending limit, a pause after a mail outage, a stopped mail sender, preparation held while a campaign change is applied, and emails waiting to retry after a temporary refusal. {% translate "Mail sender" %}
{% translate "The server runs two mail senders by default. Running means sending, or ready to send with nothing due. Halted means a fault that waiting cannot fix (for example, a mail password that no longer works) stopped all sending; today only the server operator can clear it. Not running means the sender has not reported for more than three minutes." %}
{% translate "ParishSoft refresh" %}
{% translate "A full refresh re-reads everything from ParishSoft; quick updates in between pick up recent changes. While Family emails are being sent, quick updates and daytime full refreshes wait, and run when the send ends. If a refresh would remove too much (too many Families, Members or email addresses at once), it is refused and the system keeps the data it had. Every later refresh is refused too, until the drop is fixed in ParishSoft or accepted on the server." %}
{% translate "Backups" %}
{% translate "The page can only see backups that finished. A scheduled backup that fails leaves no record, so the page can only say that none has finished since a given time. Copies made outside this application leave no record either. The backup schedule is set on the server, which this page cannot read, so there is no “next backup” time; the backup runbook describes the nightly schedule." %}
{% translate "Debug logging" %}
{% translate "Debug logs record extra detail that can include Families' personal information, so debug logging must be off in Production. In Testing it may be on on purpose. Only the server operator can turn it off, by changing the server's settings and restarting the services." %}
{% translate "Pages and emails to re-save" %}
{% translate "When the system's cleaning of email and page formatting gets stricter, a page or email saved earlier can keep markup that sending now removes. Families already get the cleaned version, so it still sends; re-saving it stores what Families actually receive. The one exception is an invitation or reminder whose Family code or link is only inside the removed markup: it can't be sent until it is fixed: go-live waits for it, and once the campaign is live its sends are refused." %}
{% translate "Version" %}
{% translate "The version each service runs and when it last started. Different versions usually mean an upgrade did not finish. A service that was removed from the server stays listed as not running for up to a day." %}
