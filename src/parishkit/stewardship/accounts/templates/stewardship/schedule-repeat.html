Sends is the shared two-way pair (components/choice-pair.html, as the report email editor's Sends). It is no setting of its own: it is drawn disabled and left out of the change gate, enabled only while shown, and ui-v1.js drops it from the form's data (formdata), so it is never posted; the server refuses it as an unknown field. It is passed errors=None: it has no errors of its own, and without it the include would read the page's error summary (``errors``, a list of message dicts) as its own and draw them as text in its line (R45). The rule's controls are the shared repeat rule (components/repeat-rule.html, #1129), the same as New scheduled email's Repeating rule, with its choices from a blank RepeatRule (Schedules.repeat_rule). None of them has a name, so nothing of the rule is posted: when Review changes gathers the form's data, the page expands it (window.ParishRecurrence, pinned by tests/stewardship/fixtures/recurrence_cases.json) into one ordinary reminder row per date in the pane's place, which the server validates, previews and confirms exactly like reminders added one at a time. A rule error is shown at its fields, in the rule's reserved error lines (#1915). From and Until start at the campaign dates being proposed (data-repeat-start and -end as drawn, then the window fields). data-repeat-zone is the saved campaign zone, which the date list (#2092) uses while the window has no time zone field. {% endcomment %}
