The rule's controls are the shared repeat rule (components/repeat-rule.html, #1129), the same as New scheduled email's Repeat, with its choices from a blank RepeatRule (Schedules.repeat_rule). None of these controls has a name, so nothing here is ever posted. The panel stays hidden until the script reveals it; the Admin portal requires JavaScript. Only the one-line summary is a live region (the date list can run to hundreds of items and is rebuilt as the Admin types), and it sits with the button above the list, its line reserved, so a growing or shrinking list never moves the button. A rule error is shown at its fields, in the rule's reserved error lines (#1915); while the rule gives nothing to add, Add these reminders waits, named by that line or by the summary, which says what is missing. The send time is a shared time entry field (data-time-entry, ui-v1.js): its "Reads as" line, refusal, blur rewrite and Save gate are the same as every other Admin time (#1117). Its zone is the rows': the browser's (schedules.browser_times, #558). Only the date-change review shows this panel, and it always takes browser times. {% endcomment %}
