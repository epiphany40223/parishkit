A read-only row (it has run, or has work prepared) has no selection box and no actions; the server refuses to change or delete one anyway (schedule_entry_views). New and Edit scheduled email review in the shared review dialog (#750) and return here once the change is applied: the reserved status line above the table (components/review-outcome.html, outside the table region, so a redraw keeps it) then says what was applied and when, and takes focus. The Delete confirmation's caution (email already sent is never recalled) is said only when a chosen schedule has sent email (R40b): the row's Delete and box carry data-confirm-caution while its delivered count is above zero, the same count as the review's notice (schedule-changes.html). A reminder of a remembered series (#469) shows a Repeats chip under its status (#2234; under it, #2250): the shared status-badge, its rule in Edit's words (schedule_views.series_rules) as its title and its screen-reader text, the short word hidden from screen readers so they hear the rule once. While the campaign wizard proposes them (admin_chrome.campaign_wizard .suggest, #1404 PR 6), the Suggested schedules panel after the table lists the suggested starting schedules (schedule_suggestions) as the table lists saved ones, each "Not saved yet", and holds the form the action row's Add these schedules and continue posts (data-direct-save, followed in place by ui-v1.js, which then opens the next step with "Suggested schedules added."). The form carries the page's version and request key (the server works the same set out again) and, after the table, the Suggested report emails (suggested_reports, #2038): per starting point a checkbox ticked when drawn, its plain-words rule, recipients and blocks, a time entry typed in this browser's zone (posted as zone) and greyed while unticked (data-enabled-when, so ticking moves nothing), and "Not saved yet". The form's complete gate holds Add while a ticked row's time is empty or unreadable, saying so in the reserved hint; a refused save draws this page again (400, redraw: on the save's own address, where the wizard is not drawn), whose time errors ui-v1.js places in each row's reserved error line. {% endcomment %}{% with suggest=admin_chrome.campaign_wizard.suggest %}
